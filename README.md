# CollabDocs

CollabDocs is a single-node collaborative plain-text editor built incrementally
according to the project plan. This repository currently contains the minimal
backend and frontend TypeScript scaffolding.

Project planning documents:

- [Architecture constitution](docs/AGENTS.md)
- [Scope](docs/SCOPE.md)
- [Implementation tasks](docs/TASKS.md)

## Workspace commands

```sh
npm install
npm run typecheck
npm run build
```
